# 200k · план тренувань

Персональний дашборд підготовки до першої двохсотки (бревет): 11 тижнів,
20.07.2026 → 04.10.2026. План, прогресія довгого виїзду, погода на дні
тренувань, чекліст бази і ручний журнал «зроблено» — все на одній сторінці.

## Запуск

Статичний сайт без збірки (ES-модулі), потрібен будь-який локальний сервер:

```bash
python3 -m http.server 8000
# або: npx serve
```

і відкрити http://localhost:8000. Просто відкрити `index.html` з диска не
вийде — браузер не вантажить ES-модулі з `file://`.

Найпростіший хостинг — GitHub Pages: Settings → Pages → Deploy from branch.
Всі шляхи відносні, працює з підпапки.

## Що всередині

```
index.html        — розмітка сторінки
css/styles.css    — вся дизайн-система (світла база, mesh-градієнти, LED-цифри)
js/plan.js        — ДАНІ ПЛАНУ — єдине місце, яке редагуєш руками
js/app.js         — рендер секцій, графік, анімації
js/weather.js     — Open-Meteo: прогноз 16 днів + геокодинг міст
js/dots.js        — крапкові цифри (5×7 LED-матриця)
js/store.js       — localStorage: локація, галочки виїздів, чекліст
```

### Погода

[Open-Meteo](https://open-meteo.com) — безкоштовно, без ключа, CORS відкритий.
Прогноз на 16 днів: стрічка в картці «Погода» + чипи днів у картках тижнів,
які вже потрапили в горизонт. Місто змінюється в самій картці (пошук або
геолокація), вибір запам'ятовується. Кеш прогнозу — 30 хв у localStorage.

Оцінка дня під виїзд: опади ≤25% + вітер ≤24 км/г + 10–29° = «топ»
(лаймова картка), далі «норм» і «так собі». Пороги — у `rideScore()`
в `js/weather.js`.

### Дата бревету

Коли з'явиться реальна дата — онови в `js/plan.js`:
`TARGET_WEEK_START`, дати тижнів 10–11, і за потреби зсунь тапер.

### Перевірка станів

Сторінка «жива» — рахує все від сьогодні. Подивитись інший день:
`?today=2026-08-20` в адресі.

## Етап 2 — Strava через MCP

Задумано так: активності зі Strava підтягуються через MCP-сервер і матчаться
з виїздами плану за датою + дистанцією. Точка стикування — `js/store.js`:
ручні `setDone/isDone/doneKm` замінюються (або доповнюються) даними Strava,
UI не змінюється. Ручні галочки — тимчасова заміна до підключення.
